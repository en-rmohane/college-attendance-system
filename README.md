# College Attendance Management System 🎓

A comprehensive web-based attendance management system for colleges with smart timetable generation.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Flask](https://img.shields.io/badge/Flask-2.3.3-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

## ✨ Features

### 👥 Multi-Role System
- **Admin**: Manage professors, subjects, generate timetables
- **Professor**: Take attendance, upload notes, create tests  
- **Student**: View attendance, take tests, download notes

### 📅 Smart Timetable Generation
- Common subjects for CSE & AD branches at same time
- Clash-free automatic timetable generation
- Lab sessions in continuous 2-hour slots

### 📊 Attendance & Reports
- Daily attendance marking (single & bulk)
- Monthly attendance reports in Excel format
- Real-time attendance analytics

### 🎯 Test Management
- MCQ-based online tests
- Auto-evaluation and scoring
- Security features (OTP, tab-switch detection)

### 📚 Academic Features
- Notes sharing between professors and students
- Notice board with targeted announcements
- Mid-term marks entry and tracking

## 🛠️ Tech Stack

- **Backend**: Python, Flask, SQLAlchemy
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Database**: SQLite
- **Templates**: Jinja2
- **Reporting**: Excel, CSV exports
